🎯 THE 30-MINUTE SETUP
═══════════════════════════════════════════════════════

Prerequisites (15 min - do once):
  1. Download & install Node.js 16+ (nodejs.org)
  2. Download & install PostgreSQL 12+ (postgresql.org)

Setup (15 min - do once):
  1. Create database (copy-paste SQL from guide)
  2. Create backend\.env file (template provided)
  3. Run npm install (in backend & frontend)

Running (2 min - every time):
  Terminal 1: cd backend && npm run dev
  Terminal 2: cd backend\frontend && npm run dev
  Browser:   http://localhost:5173

🐛 COMMON ISSUES
═══════════════════════════════════════════════════════

Q: Node.js not found?
A: Install from nodejs.org, then restart your terminal

Q: PostgreSQL won't connect?
A: Check password in .env matches your PostgreSQL password
   Verify PostgreSQL is running (check Windows Services)

Q: Port 3000 already in use?
A: Change PORT in backend\.env to 3001

Q: npm install fails?
A: Delete node_modules and package-lock.json
   Try npm install again

See SETUP_WINDOWS.md for more troubleshooting
