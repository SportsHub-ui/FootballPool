📋 PREREQUISITES (Install Once)
================================

Before you start, you need:

  1. Node.js 16+
     └─ Download: https://nodejs.org/
     └─ After install, verify: node --version
     └─ Time: ~5 minutes

  2. PostgreSQL 12+
     └─ Download: https://www.postgresql.org/download/windows/
     └─ After install, verify: PostgreSQL running as service
     └─ Time: ~10 minutes

  3. Git (Optional but recommended)
     └─ Download: https://git-scm.com/


⚙️ SETUP STEPS (One Time Only)
================================

STEP 1: Create PostgreSQL Database
──────────────────────────────────

Open Command Prompt and run:
  
  psql -U postgres -h localhost

When prompted, enter your PostgreSQL password.

Then copy-paste this SQL (see SETUP_WINDOWS.md for full script):

  CREATE DATABASE football_pool;
  \c football_pool
  CREATE SCHEMA IF NOT EXISTS football_pool;
  CREATE TABLE IF NOT EXISTS football_pool.team ( ... );
  ... (all table creation SQL)

Time: ~2 minutes


STEP 2: Create Configuration File
───────────────────────────────────

Create file: backend\.env

Content:
  APP_ENV=development
  NODE_ENV=development
  PORT=3000
  DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/football_pool
  FUNDRAISER_ADMIN_KEY=dev-secret-key-change-in-production
  JWT_SECRET=dev-secret-key
  JWT_EXPIRES_IN=7d
  FRONTEND_URL=http://localhost:5173
  LOG_LEVEL=info

Replace YOUR_PASSWORD with your PostgreSQL password!

Time: ~1 minute


STEP 3: Install Dependencies
───────────────────────────────

Open Command Prompt in project directory:

  cd backend
  npm install
  cd frontend
  npm install
  cd ..\..

Time: ~3-5 minutes

⚡ COMMON ISSUES
=================

Q: "PostgreSQL connection failed"
A: Make sure PostgreSQL is running. Check Windows Services.
   Verify password in backend\.env matches your PostgreSQL password.

Q: "Port 3000/5173 already in use"
A: Another app is using that port. Stop it or change PORT in .env

Q: "npm install failed"
A: Delete node_modules folder and package-lock.json
   Run npm install again

Q: "Command not found: node"
A: Node.js not installed or not in PATH
   Restart Command Prompt after installing Node.js

Q: I see "listening on port 3000" but frontend won't load
A: The backend is running but frontend might not have started.
   Wait a moment and try again. Make sure you're on http://localhost:5173
